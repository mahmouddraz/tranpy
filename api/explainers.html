Explainers Module

The explainers module provides model interpretability and explainability tools.

Base Classes

SHAP Explainer

class tranpy.explainers.SHAPExplainer(model, X_train, X_test=None, feature_names=None, class_names=None, n_background=100)[source]

Bases: BaseExplainer

SHAP explainer for power system stability models.

Provides SHAP value computation and visualization.

Parameters:

  • model – Trained model with predict or predict_proba method

  • X_train (ndarray) – Training data for background

  • X_test (Optional[ndarray]) – Test data to explain

  • feature_names (Optional[List[str]]) – Names of features

  • class_names (Optional[List[str]]) – Names of target classes

  • n_background (int) – Number of background samples for KernelExplainer

Example Usage:

from tranpy.explainers import SHAPExplainer

explainer = SHAPExplainer(model, X_train, X_test)
shap_values = explainer.explain_global()
explainer.plot_summary(shap_values)

LIME Explainer

class tranpy.explainers.LIMEExplainer(model, X_train, X_test=None, feature_names=None, class_names=None, mode='classification')[source]

Bases: BaseExplainer

LIME explainer for power system stability models.

Provides local and global explanations using LIME.

Parameters:

  • model – Trained model with predict_proba method

  • X_train (ndarray) – Training data for background

  • X_test (Optional[ndarray]) – Test data to explain

  • feature_names (Optional[List[str]]) – Names of features

  • class_names (Optional[List[str]]) – Names of target classes

  • mode (str) – Explanation mode (‘classification’ or ‘regression’)

Example Usage:

from tranpy.explainers import LIMEExplainer

explainer = LIMEExplainer(model, X_train, X_test)
explanation = explainer.explain_instance(X_test[0])
