Datasets Module

The datasets module provides pre-built power system stability datasets and utilities for loading and managing data.

Dataset Loaders

tranpy.datasets.load_dataset(grid, return_X_y=False, test_size=None, random_state=None, as_frame=False)[source]

Load a power system stability dataset.

Parameters:

  • grid (str) – Grid name (‘NewEngland’ or ‘NineBusSystem’)

  • return_X_y (bool) – If True, return (data, target) instead of StabilityDataset

  • test_size (Optional[float]) – If provided, split into train/test sets

  • random_state (Optional[int]) – Random seed for train/test split

  • as_frame (bool) – If True, return data as pandas DataFrame

Return type:

Union[StabilityDataset, Tuple[ndarray, ndarray], Tuple[ndarray, ndarray, ndarray, ndarray]]

Returns:

  • StabilityDataset object (default)

  • (X, y) if return_X_y=True

  • (X_train, X_test, y_train, y_test) if test_size is provided

Examples

>>> # Load full dataset
>>> dataset = load_dataset('NewEngland')
>>>
>>> # Get X, y arrays
>>> X, y = load_dataset('NewEngland', return_X_y=True)
>>>
>>> # Get train/test split
>>> X_train, X_test, y_train, y_test = load_dataset(
...     'NewEngland', test_size=0.2, random_state=42
... )
