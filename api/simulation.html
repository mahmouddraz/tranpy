Simulation Module

The simulation module provides PowerFactory integration for generating custom stability datasets.

Interface to PowerFactory for power system simulation.

This class provides a clean API for running transient stability simulations and generating training datasets.

Parameters:

  • grid (str) – Grid model name (‘NewEngland’ or ‘NineBusSystem’)

  • simulation_time (float) – Simulation duration in seconds

  • output_dir (str) – Directory for saving results

Examples

>>> simulator = PowerSystemSimulator(
...     grid='NewEngland',
...     simulation_time=10
... )
>>> dataset = simulator.run(
...     num_events=1000,
...     fault_clearing_time=[12],
...     max_load_change=[60]
... )

>>> results = simulator.run(num_events=100, random_seed=42)

Mock simulation engine that generates synthetic stability data.

This engine mimics PowerFactory’s behavior but generates data algorithmically, allowing for testing and development without PowerFactory installation.

Parameters:

  • grid (str) – Grid name (‘NewEngland’ or ‘NineBusSystem’)

  • simulation_time (float) – Simulation duration in seconds

  • random_seed (Optional[int]) – Random seed for reproducibility

Examples

>>> engine = MockSimulationEngine('NewEngland', simulation_time=10.0)
>>> results = engine.run(num_events=100)

Example Usage:

from tranpy.simulation import MockSimulationEngine

# Create mock simulator (no PowerFactory required)
engine = MockSimulationEngine('NewEngland', simulation_time=10.0)
results = engine.run(num_events=100, random_seed=42)

Dataset Generation

tranpy.simulation.generate_dataset_from_simulation(results, snapshot_type='clearing', test_size=0.2, val_size=0.2, shuffle=False, random_state=None)[source]

Generate training dataset from simulation results.

This function extracts features (bus voltage and angle at fault clearing time) and labels (stable/unstable) from simulation results.

Parameters:

  • results (SimulationResults) – SimulationResults object

  • snapshot_type (str) – ‘fault’ or ‘clearing’ - which snapshot to use

  • test_size (float) – Fraction of data for test set

  • val_size (float) – Fraction of training data for validation set

  • shuffle (bool) – Whether to shuffle before splitting

  • random_state (Optional[int]) – Random seed for reproducibility

Return type:

Tuple[StabilityDataset, dict]

Returns:

Tuple of (dataset, splits_dict) where splits_dict contains train/test/val DataFrames with features and labels

Examples

>>> results = SimulationResults.load('path/to/results.pickle')
>>> dataset, splits = generate_dataset_from_simulation(results)
>>> print(f"Dataset: {dataset.data.shape}")
>>> print(f"Train: {splits['train'].shape}")
