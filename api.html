API reference

Generic layer (tranpy_core)

Typed, immutable dataset containers.

  • TabularDataset - one feature vector and one label per sample.

  • SignalDataset - one multichannel time series and one label per sample. Samples may have different lengths; they are stored back to back in a single array, with offsets[i]:offsets[i + 1] selecting the rows of sample i. This layout lets feature extractors work on all samples at once instead of looping in Python.

Arrays are copied on construction and made read-only, so a dataset cannot be changed by accident after it has been split or fed to a model.

tranpy.datasets.detect_fault_timing(dataset, *, voltage_threshold_pu=0.8)[source]

Detect fault inception and clearing from the lowest bus voltage of each event.

  • inception: first time the lowest bus voltage drops below voltage_threshold_pu;

  • clearing: first time it is back above the threshold after the first dip. If the voltage stays low until the end, the start of the steepest recovery (slope above 0.1 p.u./s after the nadir) is used.

Mock simulation engine: a classical multi-machine model integrated with NumPy.

It replaces PowerFactory in tests, examples and method development. It is not a model of the real IEEE systems: the network is a synthetic, seeded graph with the system’s number of generators and buses. What matters is that the stability label follows from the simulated dynamics, as in a real simulator, instead of being drawn first and the features generated from it.

Model (per unit, swing equations of the classical generator model):

d(delta_i)/dt = 2*pi*f0 * (omega_i - 1)
2*H_i * d(omega_i)/dt = Pm_i - Pe_i - D_i * (omega_i - 1)
Pe_i = sum_j E_i * E_j * B_ij * sin(delta_i - delta_j)

A fault on line (a, b) depresses the electrical power of nearby machines while it lasts; clearing opens the line (B_ab = 0). Bus voltages are weighted phasor sums of the generator EMFs. A machine is out of step once its angle relative to the centre of inertia exceeds 180 degrees (latched), which defines the label.

All scenarios are integrated together (fixed-step RK4), so generating hundreds of events takes seconds.
