# Published ML transient-stability-assessment results: what is comparable to the thesis protocol

Compiled 2026-11-05 from web search and fetched source text. Numbers appear only where they were read in the fetched text of the paper (PDF text extracted with `pdftotext`, publisher HTML, or arXiv abstract/HTML page). Where only an abstract or landing page was readable, the row says so and records nothing beyond what that abstract states.

Thesis protocol for reference: German 220/380 kV model (~1,250 buses, ~155 machines), 11,159 three-phase line faults in 9 operating hours, 11.9 % unstable; task (a) pre-fault (operating point + fault location + clearing time), (b) at fault clearing, (c) early post-clearing windows; primary split = leave-one-operating-hour-out, secondary = random stratified; metrics PR-AUC, miss rate, precision, MCC, accuracy. Current: pre-fault PR-AUC 0.45 (accuracy ~0.89 vs 0.88 base rate), at clearing PR-AUC 0.993.

## 2. What is comparable to the thesis protocol, by protocol group

**Pre-fault / preventive with the contingency as input (task (a)).** This is the only group that answers the same question as the thesis' pre-fault task, and it is thin. Meghdadi et al. 2019 (#1) is the closest in spirit: ACOPF operating-point features, a fixed critical line per classifier, and a validation set whose load range deliberately extends beyond the training range (0.25-1.85 vs 0.3-1.7). But it is a 9-bus system with 455/699 scenarios, 23-28 % unstable, and the reported 0.57 % error is on a single validation set with no CI; the contingency is not an input but a per-classifier constant, so there is no fault-location generalisation. Lu & Bu 2025 (#5) is the one peer-reviewed TPWRS paper found that takes "pre-fault system state and trip location" into a GNN, i.e. the same input definition as the thesis task (a), but only the abstract was readable and it reports probabilistic TSI trajectories, not classification metrics. Zhao et al. 2024 (#6) uses steady-state (pre-fault) features and is the only study in the table that quantifies the drop when the operating scenario changes (97.5 % → 83 % / 79 % accuracy, F1 ≈ 76-78 on the target domain, single run); it also shows that at 40:1 imbalance the unstable-class rate T_TN falls to 81 % with plain cross-entropy. The Imperial/TU Delft line (#2-#4) is methodologically the right reference for "security rules with contingencies and missed-alarm costs" but no metric could be read from the sources, and #3 uses static security on a 6-bus system. The 9-bus benchmark (#21) is pre-fault by construction and explicitly recommends stratifying the split by fault location and clearing time, which supports the thesis' leave-hour-out / unseen-operating-point stance, but ships no baseline. Conclusion: no published pre-fault study with (i) a >1,000-bus system, (ii) fault location and clearing time as inputs, (iii) a held-out-operating-point split and (iv) PR-AUC or recall on a ~12 % unstable set was found; the thesis' PR-AUC 0.45 at ~0.89 accuracy therefore has no like-for-like published number, and the high accuracies in #1 and #19 should be cited as small-system, in-range or random-split results.

**At fault clearing / early post-fault windows (tasks (b), (c)).** Han et al. 2021 (#8) is the direct analogue of task (b): features at the moment of fault clearing, 19 % unstable, random split, DT unstable recall 0.935, MLP 0.926 (accuracy 0.97-0.98). Chen et al. 2022 (#9), the PESGM 2026 paper (#12), Sun et al. 2024 (#13) and Huang et al. 2024 (#10) use short post-fault windows (60 ms, 101 steps, three snapshots) and report accuracy 96.7-99.9 % and AUC up to 0.9999, i.e. in the same region as the thesis' at-clearing PR-AUC 0.993. All but #9 use random splits or unspecified splits; #9 is 10-fold random CV with ± std. The 2383-bus Polish case in #9 (3,000 samples, 33 % unstable, Acc 99.2±0.5) is the only large-system classification result found, and the thesis' German model is of comparable size. None of these report PR-AUC; the nearest imbalance-aware metrics are per-class recall (#8), TNR/TPR (#9), FNR/FPR/ROC-AUC (#13) and unstable recall / balanced accuracy (#16). Comparability caveat: random splits that mix operating points between train and test (as in #8, #9, #10, #12, #13) sample the same load levels on both sides, so the thesis' random-stratified secondary split is the fair comparison for these numbers, not the leave-hour-out split.

**Unseen operating points, unseen fault orders, unseen topologies.** Three studies hold out something: #16 (LLaTSA) holds out N-3 faults and the 40 % renewable level and reports unstable recall 95.6±1.3 % and 94.1±1.5 % over 20 seeds, the only study found with seed-level dispersion; #18 (static voltage security, not TSA) holds out a new operating point and sees F1 fall from 99.5 to 96.2 (GCN) and 91.1 (MLP), averaged over 10 runs; #6 sees accuracy drop from 97.5 to 79-83 under scenario shift. Topology-held-out results (#10 N-2/N-3; #11 unknown topologies 87.73 % vs 89.66 %; #12 40 new topologies 99.06 %; #4 ~10 % accuracy gain after database rebuilding) test a different axis than the thesis (the thesis keeps topology fixed and holds out hours). The magnitude of the drop is strongly method- and system-dependent, so these numbers justify the leave-hour-out design but are not a benchmark for it. No study was found that reports confidence intervals; dispersion, when given at all, is a ± std over folds or seeds (#9, #16) or an unquantified 10-run average (#18).

**Fixed fault lists and random splits inflate scores.** Every table row with ≥ 96 % accuracy uses a fixed, exhaustively enumerated fault list (all lines at fixed positions, few clearing times) and either a random split or an unstated split; the 2.5-9 % unstable sets in #13 still reach FNR < 1 % because both the fault set and the load range are shared between train and test. The thesis' primary protocol removes the operating point from the training support, which is the condition under which #6 and #18 show the largest degradation; comparisons to the ≥ 96 % literature should therefore be made only against the thesis' secondary (random stratified) split, and the pre-fault number should be compared with #1 and #6 with the explicit note that those are 9-bus and 39-bus systems.
